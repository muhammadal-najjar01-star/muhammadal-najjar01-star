## 👋 About Me

- 🎓 M.Sc. student in **Computer Engineering** at the **University of Genoa**, Italy (2nd year), with a B.Sc. in **Systems and Biomedical Engineering** from Cairo University (GPA: 3.7/4).
- 💼 **AI & Software Engineering Intern at Ericsson**: working on an **Agentic AI Code Review System**, where specialized LLM agents collaborate with deterministic tools to make code reviews secure, reliable, and explainable.
